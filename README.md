# 心隅 · AI校园心理健康护航平台

> 2026全国大学生数字媒体科技作品及创意竞赛 · 自主选题/移动与网络应用开发类参赛作品

面向高校心理健康教育与咨询场景的一体化Web平台，以「**AI私密陪伴 + 标准化专业测评 + IRT自适应测评 + 匿名树洞 + 危机预警闭环 + 咨询师工作台**」为核心，缓解高校心理咨询师不足、学生有情绪困扰羞于开口、危机事件发现滞后等现实痛点。

## 一、核心创新

1. **本地离线RAG智能心理咨询**：内置Qwen量化大模型 + BGE-M3向量模型 + 青少年心理知识库（考试焦虑、宿舍矛盾、学业压力、人际敏感、危机干预5大主题），**纯CPU推理、全程离线、数据不出本机**，保护学生隐私；强制共情疏导式Prompt，不做疾病诊断。
2. **高危表达识别与危机干预**：用户消息进入检索前先做关键词高危筛查，识别自杀/自伤倾向时立即拦截，给出24小时心理援助热线、医院急诊与学校咨询中心等求助路径。
3. **IRT自适应心理测评**：基于项目反应理论（Samejima等级反应模型GRM），EAP在线估计潜变量 θ、最大Fisher信息动态选题，分数越精准越自动跳过冗余题目，通常8–15题即可完成传统量表90题的测量精度。
4. **情绪 → 测评 → 树洞 多源数据融合的学生维度预警**：以学生为单位聚合不同预警来源，给出综合评价与科学分级依据，推送咨询师工作台形成「发现—处置—跟进」闭环。
5. **绿色免安装交付**：内置便携Python与全部AI模型，双击即开，无需安装环境、无需联网。

## 二、功能模块

### 学生端

- 首页（我的最近状态、统计概览）
- 心理测评：SCL-90 / SAS / SDS等专业量表，含详细介绍、答题与结果报告
- **IRT自适应测评**：压力 / 焦虑 / 抑郁三维，实时潜变量估计、风险等级与维度画像
- 我的测评：统一查看普通量表与IRT全部测评历史
- 私密心聊：本地离线AI咨询（历史会话、高危拦截）
- 情绪日记：心情记录、连续日期心情曲线（周/月/年/全部，支持断点）
- 匿名树洞：小红书式图文/音频/视频发布、点赞评论、我的帖子管理
- 减压舱：4-7-8呼吸训练等多种减压放松
- 心理成长：疗愈影音、枕边书单、心情手札（实时内容、分页、搜索）
- 预约咨询：选择咨询师在线预约、取消预约
- 个人中心：基本信息、头像上传；支持学信网（模拟）登录

### 教师端（心理咨询师）

- 首页工作台：核心指标、待办与风险概览
- 预约管理：确认/完成/取消（二次确认弹窗）、暂停预约
- 预警工单：学生维度综合预警，侧栏查看触发行为、风险分级科学依据、历史咨询/测评/预约全档案
- 数据看板：问题学生分布、心理严重程度、测评使用情况等多类型图表
- 学生树洞：以浏览学生动态为主
- 心理资讯 / 心理月刊：实时文章、往期检索、按栏目浏览
- 个人中心：执业信息；支持中国心理学会注册系统（模拟）认证登录

## 三、技术栈与数据库

- 后端：Python 3.13 + Flask 3.x + Flask-SQLAlchemy（SQLAlchemy 2.x）
- 前端：Jinja2模板 + 原生JavaScript + ECharts（本地引入，离线可用）
- AI：Qwen2.5-1.5B-Instruct 4bit GGUF（llama-cpp-python，CPU）、BGE-M3（sentence-transformers）
- RAG：本地知识库分块 → BGE-M3向量 → 余弦相似度检索 → 受控Prompt生成
- IRT：纯NumPy实现GRM/EAP/MFI，预留py-irt离线再标定接口
- 数据库：默认SQLite（`xinyu.db`，开箱即用）；可通过环境变量 `DATABASE_URL` 切换MySQL

## 四、快速开始（绿色免安装版，推荐）

1. 将整个文件夹拷贝到任意Windows 10/11（64位）电脑，路径可任意。
2. 双击 **`启动心隅.bat`**，首次启动会加载本地AI模型（约30–90秒）。
3. 浏览器自动打开，或手动访问 <http://127.0.0.1:5000>。
4. 关闭命令行窗口即停止服务。

演示账号（密码均为 `123456`）：学生 `student1` / `student2` / `student3`；咨询师 `counselor` / `counselor2`。

## 五、从源码部署（面向开发者）

```bash
# 需要Windows 64位 + Python 3.13.x
pip install -r requirements.txt
# 需自行准备模型并放置于models/（qwen GGUF、models/bge-m3），知识库位于knowledge/
python app.py
```
