# 心隅 · AI 校园心理健康护航平台

面向高校心理健康教育与咨询场景的一体化 Web 平台，以「**AI 私密陪伴 + 标准化专业测评 + IRT 自适应测评 + 情绪与危机智能筛查 + 匿名树洞 + 危机预警闭环 + 咨询师工作台**」为核心，缓解高校心理咨询师不足、学生有情绪困扰羞于开口、危机事件发现滞后等现实痛点。平台全部 AI 能力均在本地离线运行，数据不出本机，切实保护学生隐私。

---

## 一、项目介绍

### 1.1 项目背景

高校心理健康工作长期面临三方面矛盾：一是学生数量庞大而专职心理咨询师配备不足，咨询资源紧张；二是不少学生存在情绪困扰却因「病耻感」羞于当面求助，问题被拖延；三是自杀、自伤等危机事件隐蔽性强、发现滞后，传统人工排查难以做到实时。平台希望用一套**可离线、可普及、可闭环**的数字化平台，把「日常陪伴、科学测评、危机识别、人工干预」连成一条完整链路。

### 1.2 核心能力

1. **本地离线 RAG 智能心理咨询**：内置 Qwen2.5 量化大模型 + BGE-M3 向量模型 + 覆盖 10 大主题的青少年心理知识库，本地推理、全程离线、数据不出本机；强制共情疏导式提示词，不做疾病诊断。
2. **BERT 情绪识别与危机筛查**：对学生文本做情绪多分类与危机风险分类两路并行推理，结合中文关键词规则二次校验与兜底，输出七类情绪占比与高危/关注/正常三级风险。
3. **高危表达识别与危机干预**：用户消息进入检索前先做关键词高危筛查，识别自杀/自伤倾向时立即拦截，给出 24 小时心理援助热线、医院急诊与学校咨询中心等求助路径。
4. **IRT 自适应心理测评**：基于项目反应理论（Samejima 等级反应模型 GRM），EAP 在线估计潜变量 θ、最大 Fisher 信息动态选题，精度越高越自动跳过冗余题目，通常 8–15 题即可达到传统长量表的测量精度。
5. **多源数据融合的学生维度预警**：以学生为单位聚合 AI 对话、树洞、测评等不同预警来源，给出综合评价与科学分级依据，推送咨询师工作台形成「发现—处置—跟进」闭环。

### 1.3 功能模块

**学生端**

- 首页：我的最近状态、统计概览
- 心理测评：SCL-90 / SAS / SDS 等专业量表，含量表介绍、答题与结果报告
- IRT 自适应测评：压力 / 焦虑 / 抑郁三维，实时潜变量估计、风险等级与维度画像
- 我的测评：统一查看普通量表与 IRT 全部测评历史
- 私密心聊：本地离线 AI 咨询（历史会话、高危拦截、情绪识别）
- 情绪日记：心情记录、连续日期心情曲线（周/月/年/全部，支持断点）
- 匿名树洞：图文/音频/视频发布、点赞评论、我的帖子管理
- 减压舱：4-7-8 呼吸、渐进式肌肉放松、正念等多种减压放松
- 心理成长：疗愈影音、枕边书单、心情手札（实时内容、分页、搜索）
- 预约咨询：选择咨询师在线预约、取消预约
- 个人中心：基本信息、头像上传；支持学信网（模拟）登录

**教师端（心理咨询师）**

- 首页工作台：核心指标、待办与风险概览
- 预约管理：确认/完成/取消（二次确认弹窗）、暂停预约
- 预警工单：学生维度综合预警，侧栏查看触发行为、风险分级依据、历史咨询/测评/预约全档案
- 数据看板：问题学生分布、心理严重程度、测评使用情况等多类型图表
- 学生树洞：以浏览学生动态为主
- 心理资讯 / 心理月刊：实时文章、往期检索、按栏目浏览
- 个人中心：执业信息；支持中国心理学会注册系统（模拟）认证登录

## 二、技术架构

### 2.1 总体架构

平台采用**单体分层架构**：浏览器通过 HTTP 访问 Flask 服务，Flask 内部按「路由控制层 — 业务/AI 引擎层 — 数据持久层」分层组织，所有 AI 推理在同一进程内以本地模型完成，不依赖任何外部在线服务。

```
┌────────────────────────────────────────────────────────────────┐
│  浏览器：Jinja2 渲染页面 + 原生 JavaScript + ECharts 图表          │
└───────────────────────────────┬────────────────────────────────┘
                                │  HTTP / JSON（127.0.0.1:5000）
┌───────────────────────────────▼────────────────────────────────┐
│  路由控制层（app.py）：登录鉴权、页面路由、REST 接口、会话管理          │
├────────────────────────────────────────────────────────────────┤
│  业务 / AI 引擎层                                                │
│  · rag_counselor.py  本地 RAG 咨询 + 高危拦截                     │
│  · emotion_screen.py BERT 情绪识别 + 危机筛查                     │
│  · engine_irt.py     IRT 自适应测评（GRM/EAP/MFI）                │
│  · engine.py         规则情绪/危机引擎                            │
│  · scale_meta.py / news.py / build_irt_bank.py  量表/资讯        │
├────────────────────────────────────────────────────────────────┤
│  数据持久层：Flask-SQLAlchemy（SQLAlchemy 2.x）                   │
│  SQLite（默认）/ 可切换 MySQL；向量缓存、本地知识库                  │
└────────────────────────────────────────────────────────────────┘
```

### 2.2 技术栈

| 层次          | 技术选型                                                     |
| ------------- | ------------------------------------------------------------ |
| 后端框架      | Python 3.13、Flask 3.x、Flask-SQLAlchemy、SQLAlchemy 2.x、Werkzeug |
| 前端          | Jinja2模板、原生 JavaScript、ECharts、CSS                    |
| 数据库        | SQLite；可通过环境变量 `DATABASE_URL` 切换 MySQL             |
| 大语言模型    | Qwen2.5-1.5B-Instruct，llama-cpp-python加载                  |
| 向量模型      | BGE-M3，sentence-transformers加载，FP16                      |
| 情绪/危机模型 | 基于Transformer的情绪多分类模型与自定义BERT 危机模型（transformers + torch） |
| 科学计算      | NumPy、SciPy、scikit-learn；IRT引擎以纯NumPy实现             |
| 图像处理      | Pillow（支持头像/图片上传）                                  |

### 2.3 本地 AI 模型与数据资产

| 路径                                       | 作用                                     |
| ------------------------------------------ | ---------------------------------------- |
| `models/qwen2.5-1.5b-instruct-q4_k_m.gguf` | 离线对话生成（4bit 量化）                |
| `models/bge-m3/`                           | 文本向量化（BGE-M3）                     |
| `models/emotion-bert/`                     | 情绪多分类（11类原始标签 → 7类目标情绪） |
| `models/psyguard/`                         | 危机风险分类（11类 → 高危/关注/正常）    |
| `knowledge/`                               | RAG原始语料，10 个 Markdown主题文档      |
| `chroma_db/kb_embeddings.pkl`              | 知识库向量缓存，避免重复编码             |
| `data/irt_bank.json`                       | IRT题库                                  |
| `data/emotion_rules.json`                  | 情绪/危机标签、关键词与阈值规则配置      |

### 2.4 RAG 与 IRT 工作原理

- **RAG 流程**：知识库按 `##` 分块 → BGE-M3 编码并归一化 → 与用户问题向量做余弦相似度检索 Top-K → 组装受控提示词（含上下文预算管理）→ Qwen 生成共情回答；长度截断时自动续写一次。
- **IRT 流程**：首题从 θ=0 处信息量最大的题目开始；每作答一题，用 EAP（期望后验，161 点网格 + 标准正态先验）重新估计 θ 与标准误 SE，再用最大 Fisher 信息法选择下一题；当 SE≤0.30 且作答≥5 题或达到题数上限时结束，输出 T 分、风险等级与维度画像。

## 三、安装运行指南

### 3.1 安装使用过程

1. 将整个文件夹拷贝到任意 Windows 10/11（64 位）电脑，支持中文路径安装。
2. 双击 **`启动程序.bat`**。首次启动会加载本地 AI 模型，约需 30–90 秒，请耐心等待。
3. 数秒后浏览器自动打开；若未自动打开，请手动访问 <http://127.0.0.1:5000>。
4. 关闭命令行窗口即停止服务。

> 启动脚本会自动设置离线环境变量（`HF_HUB_OFFLINE`、`TRANSFORMERS_OFFLINE` 等），并以 `run_server.py` 守护进程方式运行；若模型加载期发生原生崩溃，守护进程会自动延时重启（最多 5 次）。
